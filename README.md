# Tarea 3

Para esta tarea se implemento que un usuario pueda agregar comentarios a las actividades que estén publicadas en la página y que se muestren estadisticas de las actividades. Para hacer lo primero se agrego a la base de datos una nueva tabla para almacenar comentarios con un nombre, el cuerpo del comentario, fecha de creación y un id de actividad asociada al comentario, para que se muestren en pantalla solo los comentarios de una actividad especifica, se creo una query que devuelve todos los comentarios que esten asociaodas a un id de actividad específico, con ello esto me devuelve los comentarios específicos y los muestro en pantalla. Para poder crear, hice un formulario pequeño que se despliega cuando un usuario quiere agregar un comentario, este le pide al usuario agregar un nombre y el cuerpo del comentario, luego este lo envía, lo que hace la aplicación por detrás es validar los datos que se entregaron y los guarda en la base de datos con la fecha y hora actual de la creación de este.

Para la parte de las estadísticas, se crearon tres urls distintas donde se almacenaban los datos necesarios para cada gráfico, luego se realizaba un fetch para obtener esos datos de las urls y se creaban las tablas con esos datos.
